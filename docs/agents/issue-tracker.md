# Issue Tracker

- **类型**: GitHub Issues(`Hi-Barry/pi-courier`,公开仓库)
- **工具**: `gh` CLI(已登录 `Hi-Barry`)
- **Spec 约定**: 标题 `[Spec] <主题>`;body 用 to-spec 模板(Problem Statement / Solution / User Stories / Implementation Decisions / Testing Decisions / Out of Scope / Further Notes),中文撰写。
- **子票约定**: spec issue 下按 `票 N(issue #M)` 拆分,由 to-tickets 产出。
- **Triage 标签**: 默认五角色,均已建:`needs-triage` `needs-info` `ready-for-agent` `ready-for-human` `wontfix`。
- **注意**: 仓库公开,issue 内容需面向公开;私人记录一律写 `docs/DEVLOG.md`(gitignored)。
- **PRs as a request surface**: off。
